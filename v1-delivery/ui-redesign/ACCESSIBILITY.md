# Accessibility

- Capture states use text plus an icon, not color alone.
- Buttons expose a button role and the visible label.
- Start is disabled until retention, purpose, and a consent assertion exist, and the missing item is named.
- Dynamic Type and a 320×568 viewport were pumped without an exception.
- Reduce Motion sets the recording orb animation duration to zero and skips the glow.
- Destructive delete stays behind confirmation.
- Contrast uses off-white on charcoal in dark themes and near-black on off-white in Quiet Light. Accent text is dark on luminous green, blue, and amber, and light on the Quiet Light green.
