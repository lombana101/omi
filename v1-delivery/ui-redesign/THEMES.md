# Themes

Stored locally under SharedPreferences key `privacy_visual_theme`. No account, network, credential, or transcript data.

| Theme | Accent role |
|---|---|
| Signal Green | Default. Near-black, charcoal, vivid green. |
| Electric Blue | Same layout, blue/cyan accent. |
| Warm Ember | Same layout, amber accent. |
| Quiet Light | Soft off-white surfaces, restrained green accent. |

Settings shows a compact preview, the name, and a check on the selected theme. The change applies immediately and survives relaunch.
